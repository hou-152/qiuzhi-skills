# 求职 Skill 工具箱

把求职问题整理成能执行的任务：拆 JD、改招呼语、练面试、复盘投递，也能**帮你写一段可直接交给另一个 AI 的提示词**。

适用于支持 Agent Skills 的客户端。可以直接贴材料开始，不需要先搭知识库。

## 安装

```bash
npx -y skills add hou-152/qiuzhi-skills -g --all
```

只安装提示词与分流入口：

```bash
npx -y skills add hou-152/qiuzhi-skills -g --skill qiuzhi-dispatch
```

只装主入口时仍能生成独立提示词；直接调用其他专业入口需要安装对应 Skill。已有同名定制版时，先在新项目试用，保留原定制文件。

## 帮我写提示词

直接说你要把什么交给 AI：

> 使用 qiuzhi-dispatch，帮我写一段给 AI 的提示词。我想判断下面这个产品实习 JD 值不值得投。我会提供 JD 和两段真实项目经历，请要求它逐条对证据，不能编经历。最后给匹配表、缺口和下一步。

你会得到一段包含**任务、背景、材料、步骤、输出格式、验收条件和权限边界**的提示词。已有信息直接带入；缺的材料会明确标出来。它能脱离当前聊天使用，不依赖接收方安装这些 Skill。

其他例子：

- “帮我写提示词，让 AI 陪我练项目深挖，一次只问一个问题。”
- “把我投了没回音的情况整理成提示词，要求区分简历版本和投递批次。”
- “帮我改这段提示词：保留我给的事实，删掉空话，补清输出和验收标准。”

如果想直接完成工作，就说“直接帮我做”。主入口会选好能力，交付一段**可直接发送的调用提示词**（例如「使用 qiuzhi-agent，帮我拆这个 JD……」），你发送后由对应入口执行。**主入口自己不执行业务动作，也不替你发送任何东西。**

## 五个入口

| Skill | 适合交给它的事 |
|---|---|
| `qiuzhi-dispatch` | 帮写提示词、任务分流、需要时组合专业能力 |
| `qiuzhi-agent` | JD 拆解、招呼语、局部经历改写、面试稿、背调，以及明确授权的本地记录写入 |
| `qiuzhi-coach` | 面试与求职陪练：判断、依据、体检、下一步 |
| `qiuzhi-course` | 求职方法与判断标准，按问题加载 12 张方法卡 |
| `qiuzhi-delivery` | 用本人投递记录做诊断、周盘和登记草稿 |

“只要登记草稿”交 delivery；“把已确认记录写进这个文件”交 agent。普通方法问答交 course，个人问题反馈交 coach。

## 主动推进（可选）

不想自己记每条线索的下一步，可以配一个本地状态文件做到期提醒（脚本随包在 `qiuzhi-dispatch` 的 `scripts/` 内）：

```bash
mkdir -p .qiuzhi && cp .agents/skills/qiuzhi-dispatch/assets/state.example.json .qiuzhi/state.json   # 按自己线索改
python3 .agents/skills/qiuzhi-dispatch/scripts/smart_push.py --state .qiuzhi/state.json
```

直接克隆仓库而不是 `npx` 安装的话，把上面两处路径前缀换成 `skills/qiuzhi-dispatch/…` 即可。

有到期项时输出结构化提醒（哪条线索、该做什么、逾期几天、是否需要本人决定），没有则返回 `NO_ACTION_NEEDED`。脚本只读状态文件并追加一条扫描记录；涉及对外发送、薪资承诺、买票动身、offer 取舍的动作**只做提醒标记，发送与决定始终由本人执行**。

## 设计：逆熵

这套工具箱的顶端设计只有一个词：**逆熵**。

不加治理的求职工作流会自然熵增——口径漂移、副本分叉、记录丢失、把“好像”写成“确认过”。所以全部设计都在对抗它：一个任务一个认领入口、事实必须有出处、缺材料时明确说缺什么而不是编造、生成物可脱离原对话独立使用、检查脚本让结构问题在交付前拦截。写提示词而不是替你执行，也是同一原则：编排与执行分离，动作离开你的账号之前，永远停在你手里。

## 材料与运行依赖

- 一个能读取 Skill 的 AI 客户端；生成提示词不需要 API 密钥或额外服务。
- 运行包检查和投递版本脚本需要 Python 3.9 或更新版本，只使用标准库。
- 可以在聊天里贴 JD、经历、回答或投递记录。可选本地材料模板放在 `skills/qiuzhi-dispatch/assets/`；只有需要保存时才建立 `.qiuzhi/` 目录。
- 调研公司、薪酬市场或其他时效性事实需要宿主提供联网能力；没有联网时会标明未核实。

## 使用边界

只依据用户提供或授权读取的材料，不编经历、结果或引用，不把团队和第三方成果记为本人贡献。不代投递或发送求职消息，不做销售岗位内容，不默认公开个人材料。

本仓库是通用工作流与空白模板，未打包私人简历、投递记录、课程逐字稿、第三方 Skill 或账号凭证。`qiuzhi-course` 是求职方法入口；需要某门课程原话时，请提供有权使用的来源，包内不附课程原文。
