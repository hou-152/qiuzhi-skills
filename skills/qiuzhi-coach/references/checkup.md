# 陪练判据

以下是本包的通用检查方法，不是课程引文。按具体问题选用。

| 检查项 | 要核对的证据 | 允许的结论 |
|---|---|---|
| 岗位相关性 | JD 的实际职责与所展示经历 | 指出匹配与缺口；缺资料不能判不匹配 |
| 事实完整性 | 行动归属、时间、数字来源与统计范围 | 指出哪一句已确认、待核实或仅内部；不能因整段可信就接受所有数字 |
| 表达清楚 | 阅读者能否理解做了什么、为何有用 | 给具体问题与改法；实际改稿需执行授权 |
| 求职反馈 | 同版本、同渠道、同观察期的记录 | 给有条件的观察；单样本不足以证明因果 |
| 行动完成度 | 用户反馈、成品、既有进度记录 | 区分没做、在做、做完未验证；不把在建状态当失败 |
| 来源可靠性 | 原文与二手转述、发布时间、冲突信息 | 说明证据覆盖范围；查不到来源时保留未知 |

建议输出：

- 判断：结论＋成立条件。
- 依据：事实与来源；若是推断，列出前提及会推翻判断的新证据。
- 体检：最关键的问题或“本次未发现”；避免泛化到人格与能力。
- 下一步：动作＋怎样算完成。

记录进度时只保留任务相关摘要，不把整段私人材料复制到日志。
