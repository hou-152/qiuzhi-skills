# 可选材料模板

普通使用只需聊天中提供任务与材料。用户明确要求建立本地材料库时，才将下面模板复制到用户指定项目的 `.qiuzhi/`，同名文件存在则先读取，不覆盖。

| 模板（相对本文件） | 可选目标 | 用途 |
|---|---|---|
| [个人条件](../assets/profile.example.md) | PROFILE.md | 求职目标、已确认条件、当前有效简历版本 |
| [经历证据](../assets/evidence.example.md) | EVIDENCE.md | 本人贡献、材料出处、使用范围 |
| [投递记录](../assets/ledger.example.csv) | LEDGER.csv | 逐条投递的版本、状态与下一步 |
| [进度](../assets/progress.example.md) | PROGRESS.md | 用户要求保存时追加可续接记录 |
| [来源](../assets/sources.example.md) | SOURCES.md | 用户有权使用的方法材料与版本信息 |

将材料库保留在本地。把模板复制到公开仓库不代表填写后的个人材料也适合公开。
