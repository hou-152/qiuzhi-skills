# 简历事实呈现

用途：让招聘者快速看到目标岗位与可信证据之间的关系。

判断标准：方向清楚，相关经历靠前，每条描述都能解释本人动作与结果范围。长度和版式服务阅读，不把固定页数当绝对规则。

步骤：
1. 先选目标岗位与关键职责，再从已确认经历中筛选证据，避免把所有经历堆上去。
2. 每条围绕任务背景、本人动作、交付或结果组织，删掉没有事实支撑的能力形容词。
3. 有数字时说明口径；没有可靠数字时写清完成的功能、流程、文档或被验证的反馈，不补造百分比。
4. 同一经历投不同方向，可以调整重点和顺序；时间、角色、成果与归属必须一致。
5. 核对联系方式、日期、链接、格式和导出后的可读性；附件、在线资料页与作品集保持同一事实口径。

验收问题：读者能否看出投什么岗？能否指出每项贡献是谁做的？结果是否可核？是否存在职责清单却没有交付？链接能否访问？每句话能否承受追问？

边界：团队结果不自动归个人，使用工具不等于开发工具，练习项目要标练习。方法说明可给空白句式；用户的具体改写交执行入口，不在这里重写整份简历。
