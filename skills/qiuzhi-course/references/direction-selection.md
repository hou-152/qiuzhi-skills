# 求职方向选择

用途：把抽象喜好变成可以验证的岗位选择。

判断标准：方向包含工作内容与现实约束，并有能力或学习意愿的依据，不能只以行业热度做结论。

步骤：
1. 先写不能妥协的条件，如地点、可到岗时间、最低可承受收入与资格限制；区分硬约束和偏好。
2. 为候选方向收集实际 JD，比较日常任务、入门要求、产物形式及成长路径。
3. 分别检查兴趣、已有证据、补齐成本、机会可获得性与生活约束。市场情况需有近期来源。
4. 对未知较多的方向安排小规模验证，如完成一个真实练习、体验产品或研究典型任务，不把短暂喜欢直接等同适合。
5. 选择少量优先方向和备选方向，写出保留或排除理由，以及哪些新证据会改变判断。
6. 按反馈复查选择；一次被拒不足以否定方向，大量尝试也不能代替检查硬门槛。

对照字段：方向｜典型任务｜现有证据｜关键缺口｜现实约束｜验证动作｜暂定优先级。

验收：每项选择能解释依据，主观偏好与市场事实分列，没有把未知自动判成不适合。工具可降低部分执行成本，但不能自动替代资格或专业能力。

边界：本卡提供选择框架，不凭有限信息替用户决定职业。行业趋势与机会数量未实时核验时必须注明。
