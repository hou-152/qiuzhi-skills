# 入职初期校准

用途：尽早明确工作目标、交付标准和协作方式，减少无方向的返工。

判断标准：知道任务给谁用、支持什么决策、何时交付、谁确认合格，以及哪些事情需要先请示。

步骤：
1. 为当前任务确认使用者、目标、范围、期限和优先级；不清楚时先问影响最大的缺口。
2. 阅读获准访问的既有产物与规范，区分参考格式和必须遵守的标准。
3. 先交小样或提纲确认方向，再逐步展开；缺少历史样本时用验收问题和早期反馈替代，不无限等待。
4. 提问时附已查资料、当前理解、卡点和候选做法。紧急、越权或高影响事项及时找负责人，不能机械地先问 AI。
5. 记录反馈与修改原因，把重复流程整理成输入、步骤、产物、检查点和异常处理。
6. 定期检查是否获得清晰反馈、适度责任与支持；成长判断基于具体任务变化，不只看岗位称谓。

验收：下一项同类任务能复用方法，交付标准可由负责人确认，关键问题没有靠个人猜测掩盖。

边界：内部文件只能在授权环境内处理；不得为使用外部工具默认上传公司资料。方法不代替团队制度或直属负责人安排，个人任务产物需另走执行入口。
