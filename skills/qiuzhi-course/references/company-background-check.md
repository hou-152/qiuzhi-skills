# 公司背调方法

用途：为岗位判断和面试准备收集可核信息，识别需要进一步确认的问题。

判断标准：公司主体、业务、岗位、个人相关证据分别清楚；观察、推测与未知不混写。

步骤：
1. 从招聘信息核对企业全称、招聘主体与官方联系入口。同名公司不能凭简称合并。
2. 优先查官方登记、官网、招聘页、产品文档和正式公告，保存来源与查看日期；必要时用其他来源交叉核对。
3. 依据岗位挑选相关产品、内容或服务体验，记录实际看到的现象及范围。
4. 把观察改成中性问题，例如某项功能面向哪些用户、团队怎样衡量成果。更新频率低不能直接推出经营困难。
5. 用 JD 明确工作内容、汇报关系和近期交付，把公开资料无法回答的部分留给面试确认。
6. 对费用、身份不一致或异常承诺等疑点进一步核对；单条记录既不能证明诈骗，也不能证明安全。

记录字段：核对对象｜信息或观察｜来源与日期｜可信范围｜待确认问题。

验收：关键结论有来源，推断有标识，未知没有被填成内部内幕。匿名评价可作线索，不能独立承担定论。

边界：具体公司现状需要实时核验；无法联网就明确未核，不使用过时印象。实际公司报告交执行入口。本卡不提供法律认定。
