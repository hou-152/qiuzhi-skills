# 经历母资料库

用途：把零散回忆整理成能够复查的事实，供简历、作品集和面试复用。

判断标准：一条经历至少能说清发生了什么、本人负责什么、留下什么产物、事实从哪里核对。结果可以是完成的产物或已知反馈，不强求业务数字。

步骤：
1. 从最近做过的作业、项目、活动、实习任务开始，先列事件，不先评判是否足够优秀。
2. 对一段经历依次回忆背景、目标、参与者、本人职责、关键动作、遇到的问题、处理依据、产物与结果。
3. 记录时间范围和证据位置。数字注明统计对象、期间、单位与获取方式；估计数单独标注，不转成精确实绩。
4. 分开记录本人、团队、外部工具的贡献；对不确定信息标待核实，对不可公开信息标仅内部。
5. 用现有文件或记录核对重要说法，保留冲突及待确认问题。访谈时每轮聚焦 1–2 个问题，避免一次填完长问卷。

可复用字段：事件名称｜时间｜背景与目标｜本人职责｜关键动作与依据｜产物｜结果及口径｜团队或工具贡献｜证据位置｜公开范围｜待核信息。

验收：任选一条公开说法，都能回到记录解释；想不起的字段仍为空或待核，没有用模板补出经历。一般方法到此结束；真实访谈和条目编写交执行或陪练入口。
