# 作品集证据展开

用途：补充简历容纳不下的过程、判断与产物，让读者能够检查贡献。

判断标准：读者无需猜测，就能知道解决的问题、本人负责范围、关键决策以及最终交付到哪一步。

步骤：
1. 选择最能证明目标岗位能力的少量项目，数量由证据质量和阅读成本决定。
2. 首页提供目标方向、项目入口和适度联系方式；只放用户明确同意公开的信息。
3. 项目页按问题、限制条件、分工、关键选择、实施证据、结果与局限组织。图片各自回答一个问题，配简短说明。
4. 标注演示、练习、原型和正式使用状态。没有真实使用数据时，仅说明完成与验证了什么。
5. 对照简历检查时间、角色、指标和成果状态；检查手机阅读、链接权限与附件大小。
6. 为关键决策准备解释：还有哪些选项，为什么这样选，证据能证明到哪里。

验收：项目内容可导航、证据与主张相连、本人贡献可区分、未知与失败没有隐藏。删除或脱敏保密信息需要逐项判断，不能假定公司内部截图可公开。

边界：本卡交结构与检查方法。制作个人项目页交执行入口；上线发布需另有明确授权。
