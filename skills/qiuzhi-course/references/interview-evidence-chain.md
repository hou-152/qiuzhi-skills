# 面试证据准备

用途：让经历陈述经得起围绕细节、分工和判断的追问。

判断标准：能够解释做过什么、本人做了哪部分、为什么采取该行动、如何知道结果。知道方法和实际做过必须分开。

步骤：
1. 从 JD 选核心任务，各找一段相关经历；先选证据，再设计说法。
2. 整理背景、目标、本人行动、结果与局限，重点放在决策和具体动作。
3. 对每段追问三层：发生了什么；为何如此处理；依据和验证在哪里。
4. 将卡点分成知识不足、证据缺失、表达不清和判断未形成，分别补学习、回查记录、压缩表达或重做分析。
5. 准备针对业务和岗位的反问。公开观察只能形成假设，不当作公司内部事实。
6. 对不会的问题明确已有理解与未知；对没做过的任务可以讲处理思路，不能编成过去经历。

验收：每个结果都有范围，个人贡献独立可述，数字能解释口径，不把流畅背诵当作理解。可用匿名描述解释保密项目，但不透露受限数据。

边界：只给准备方法和自检问题。个人答稿交执行入口；逐轮问答、点评与复练交陪练入口，不从本卡自动开始模拟。
